# Architecture

`product-studio` and `product-recheck` are the two public skills. Their bodies are the orchestration contracts. Internal agent roles, core capabilities, supporting workflows, schemas, templates, pattern libraries, and optional adapters are resources loaded progressively, and `product-recheck` reads the same set. Local YAML state is the canonical cross-session memory; Markdown artifacts are the human-reviewable outputs.

One artifact is an exception to that split. The Behavior Spec is canonical at `.product-studio/artifacts/behavior-spec.md` and mirrored byte-for-byte to `docs/agent/BEHAVIORS.md`, because the implementing agent, the reviewer, and CI need it tracked in git beside the code it describes. `scripts/validate_behavior_spec.py --mirror` is the only thing keeping the two copies honest. The `<!-- behavior-spec/v1 -->` marker on line 2 is a shared contract with the `workflow-init` skill, which emits a conforming skeleton for repositories that never ran product-studio; changing the format means bumping the marker in both.
