# Workflow

The lifecycle is QA-first and phase-oriented: goal intake → idea validation → house rules → stage/mode recommendation → user confirmation → autonomous phase execution → done-bar review/repair loop → phase checkpoint → next phase. For a raw or vague idea, idea validation runs a bounded, cited research pass and a mandatory continue-or-refine checkpoint before intent extraction goes any further, looping on refine until the user explicitly confirms. Stage and mode remain independent, and the confirmed mode compiles into a `workflow_profile` that every downstream gate reads — the spec gate, the review requirement, the behavior cap, the CI ladder, the PR expectation, and whether a deployment may be planned. Prototype, Hackathon, Indie, SaaS, Startup, and Production paths optimize different MVP and planning decisions. Hackathon short-circuits it too, differently: no research pass, 5–9 behaviors, one high-signal check chosen by where the demo actually fails, a written and rehearsed demo script, and a fallback for the one live integration. Prototype mode short-circuits the lifecycle: idea validation → one mocked flow → clickable prototype → verdict, with its own done bar and a single core-logic test. The agent asks focused questions at consequential boundaries, not after every intermediate artifact.

End to end the shape is **Discover → Specify → Red → Green → Refactor**. Discover is intake, product, research, and design. Specify turns the Design Contract into a Behavior Spec — `BH-###` behaviors with Given/When/Then and observable signals — and then attacks that spec for ambiguity, recording each finding as an `AM-###` with two readings, the user-visible difference between them, and the decision needed. An ambiguity left open blocks the Implementation Brief. Red, Green, and Refactor belong to the implementing agent, which reads the Behavior Spec and names the `BH-###` in every test it writes.

`/product-recheck` re-enters the loop mid-development: it reconstructs the product from code, diffs that against intent, behaviors, and tests, and returns a Continue / Redirect / Cut / Stop verdict with behavior and test deltas.
