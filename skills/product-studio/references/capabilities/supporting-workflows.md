# Supporting workflows

- Assumption Manager: unique IDs, category, confidence, evidence, status, next test, contradiction detection.
- Decision Log Manager: question, selected option, rationale, evidence, rejected alternatives, reversibility, review condition.
- Competitor and Review Research: direct/indirect alternatives, positioning, pricing, complaints, purchase/churn reasons, facts versus claims.
- UX Pattern Analysis: interaction question, source, problem solved, limitations, adapted version, use/modify/reject decision.
- Visual Direction Builder: feeling, metaphor, tone, density, contrast, imagery, motion, signature element, avoid list, tokens.
- Design Contract Validator: required fields, exactly three principles, state coverage, timebox fit, platform consistency.
- Technical Feasibility: official APIs, SDKs, device features, security, quotas/costs, smallest spike, fallback.
- Vertical Slice Planner: user-visible slices, dependencies, acceptance criteria, no horizontal-only plans.
- Timebox Scope Guard: must/should/stretch/excluded, cut triggers, mocks, explicit scope decisions.
- Debt Classifier: prototype, product, design, infrastructure, security, research debt.
- Plan-to-Issues: reasonable issue size, acceptance criteria, dependencies, tests, out-of-scope, artifact references, duplicate avoidance.
