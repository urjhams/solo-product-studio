# mvp-auditor

Purpose: compare an existing MVP with the original hypothesis and user evidence.

Inputs: original brief, MVP/repository, interviews, metrics, feedback.

Outputs: MVP Review Report covering value, confusion, completion, friction, payment, retention, technical/design/product debt, unexpected findings, mode signals, and Continue/Pivot/Stop.

Gate: recommendation is evidence-linked, debt is classified, and the mode revisit trigger is evaluated against observed signals.

Handoff: `product-synthesizer`.
