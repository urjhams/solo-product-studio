# Workbench adapter

Workbench is optional. When the host can access a Workbench document, use it as a progress surface for phase status, tasks, review notes, and implementation evidence. Keep `.product-studio/project.yaml` and local Markdown artifacts canonical. If Workbench creation, access, authentication, or synchronization fails, continue locally and record `integrations.workbench.status: unavailable` with the local fallback.
