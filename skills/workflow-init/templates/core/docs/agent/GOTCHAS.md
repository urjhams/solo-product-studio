# Gotchas — hard-won operational facts

Things that cost a debugging session to learn and are not derivable from the code.
**Add an entry the moment something non-obvious costs you time** — same commit as the fix.
Delete entries that stop being true. This is the file to brief subagents at (never `STATE.md`).

Format: one bullet per fact — symptom, cause, fix/recipe. Group under `##` headings per
component when the file grows.
